# Prompting

A prompt is a specification for one turn. It has a goal, constraints, and the context the model would otherwise invent.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## Goal

The outcome, in one or two sentences.

## Constraints

The library, the file to edit, and the things to leave alone.

## Examples

One existing type or test that shows the local style.

## Output shape

A patch, a list of options, or a question. Say which one you want.

## System and standing instructions

Rules that apply to every turn live in an instruction file, not in every prompt.
