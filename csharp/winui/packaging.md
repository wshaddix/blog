# Packaging

A packaged app is an MSIX. An unpackaged app is an executable you copy. They differ in identity, updates, and which APIs work.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## Packaged

An identity, a clean install and uninstall, and the Store.

## Unpackaged

An exe next to its files. Fewer sandbox rules. You own updates.

## Choosing

Store distribution versus an internal tool.

The permissions a package must declare.
