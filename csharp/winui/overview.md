# WinUI 3

WinUI 3 is the native Windows UI on the Windows App SDK. It uses the shared XAML and MVVM pages.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

- [Packaging](/csharp/winui/packaging) - Packaged MSIX and unpackaged deployment.
- [Authentication](/csharp/winui/authentication) - OpenID Connect and the Windows account broker.

## Windows App SDK

The runtime WinUI 3 ships with. It is not the old UWP Windows SDK.

## What is shared

XAML, view models, and the API client. Windowing and packaging are here.
