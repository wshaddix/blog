# Feature Files

A feature file is the spec. The sentence is the contract. The binding is an implementation detail.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## Feature and scenario

One capability, and one example of it.

## Given, When, Then

Context, action, and the outcome a reader can check.

## Scenario Outline

The same steps with an Examples table.

## Background

Steps that every scenario in the feature starts from.

## Tags

A tag that selects a scenario in CI, and a tag that marks a scenario still pending.

## Rules

A business rule grouping related scenarios.
