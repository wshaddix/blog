# Cookie Authentication

Cookie authentication is the session for a browser app, including Blazor.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## The cookie

HttpOnly, Secure, and SameSite.

## Sign in and sign out

Issuing the cookie and deleting it.

## Sliding expiration

How long a session lives.

## CSRF

A cookie is sent automatically. State-changing requests need a token.

## Data protection

The key ring that encrypts the cookie. See the security page.
