# Minimal APIs and Controllers

ASP.NET Core has two ways to declare an endpoint. Pick one per project and stay with it unless a feature forces the other.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## Minimal APIs

A route mapped on the builder. Filters and endpoint metadata.

## Controllers

A class, attributes, and filters.

## Choosing

Size of the API, filters you need, and the style of the rest of the solution.

## The handler

A method that takes a request and returns a result. Business rules stay out of it.
