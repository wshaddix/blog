# Tools, Resources, and Prompts

Tools do something. Resources are data the model can read. Prompts are reusable instructions.

*This page is an outline. The sections will be filled in over time, including a C# sample where the topic has one.*

## Tools

A method, a name, a description, and a schema for the arguments.

## Resources

A URI the client can read. Static resources and templated ones.

## Prompts

A prompt template with arguments.

## Descriptions

The text the model uses to decide whether to call the tool.

## Errors

A tool failure the client can show, distinct from a protocol failure.
